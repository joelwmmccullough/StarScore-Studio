# Fonts bundled with StarScore Studio for the Starsign house style

- **Jost** (Jost-VariableFont_wght.ttf, Jost-Italic-VariableFont_wght.ttf) — indestructible type*, SIL Open Font
  License 1.1. Italic texts; also stands in for Futura (staff text, text lines, expressions in the house style) on
  computers without Futura. Futura itself is not bundled: it comes with macOS, and Apple's licence doesn't allow
  copying it to other computers.

TT Modernoir (titles, part names, the arrangement label) is not bundled: the TypeType trial licence allows internal
testing and evaluation only and doesn't allow passing the font files on.

Registered at startup in src/engraving/engravingmodule.cpp, from src/engraving/data/fonts/fonts_Starsign.qrc.
